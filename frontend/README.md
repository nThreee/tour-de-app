# Javascript Pure Frontend Template (English)

Basic pure JavaScript template for displaying, adding, editing, and deleting products in a school cafeteria. No frameworks, no build tools, no dependencies — just open `index.html` in a browser.

## Running the app

The application requires a running backend API at `http://localhost:8080`.

Open `index.html` directly in a browser (double-click the file).

## File Structure

- `index.html` - HTML structure and script loading.
- `src/api.js` - Communication with the backend (GET, POST, PUT, DELETE).
- `src/App.js` - Application logic and state management.
- `src/ProductForm.js` - Form for adding and editing.
- `src/ProductTable.js` - Rendering the list of products.
- `src/index.css` - Basic styling.

# Javascript Pure Frontend Template (Čeština)

Základní šablona v čistém JavaScriptu pro zobrazení, přidávání, úpravu a mazání produktů ve školním bufetu. Žádné frameworky, žádné build nástroje, žádné závislosti — stačí otevřít `index.html` v prohlížeči.

## Spuštění

Aplikace vyžaduje běžící backend API na adrese `http://localhost:8080`.

Otevřete `index.html` přímo v prohlížeči (dvojklik na soubor).

## Struktura souborů

- `index.html` - HTML struktura a načítání skriptů.
- `src/api.js` - Komunikace s backendem (GET, POST, PUT, DELETE).
- `src/App.js` - Aplikační logika a správa stavu.
- `src/ProductForm.js` - Formulář pro přidání a úpravu.
- `src/ProductTable.js` - Vykreslení seznamu produktů.
- `src/index.css` - Základní stylování.
